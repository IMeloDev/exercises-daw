I. ¿Qué es HTML? Etiquetas y atributos

HTML (HyperText Markup Language) es el lenguaje con el que se escriben las páginas web. Es un lenguaje de hipertexto: permite escribir texto de forma estructurada usando etiquetas que marcan el inicio y el fin de cada elemento. Además de texto, una página puede tener imágenes, sonido o vídeo, así que es un documento multimedia.

  • Los archivos deben tener extensión .html o .htm.
  • El navegador interpreta el código y muestra la página resultante.
  • En clase escribimos el código con Notepad++.

► Etiquetas

  • Etiqueta de apertura: va entre < y > y puede llevar atributos. 
    <identificador atributo1="valor" atributo2="valor">
  • Etiqueta de cierre: va entre </ y > y NUNCA lleva atributos. 
    </identificador>
  • Algunas etiquetas no tienen cierre: <br>, <hr>, <img>, <meta>.

► Atributos

Añaden propiedades a una etiqueta. Se escriben siempre en la etiqueta de apertura con la forma nombre="valor".

► Anidar etiquetas

Se pueden meter etiquetas dentro de otras, pero nunca se pueden cruzar: la última que se abre es la primera que se cierra.

✔ Correcto: 
<p align="center"><font color="#993366">Hola</font></p>
✘ Incorrecto: 
<p align="center"><font color="#993366">Hola</p></font>

II. Estructura básica de una página

Toda página HTML tiene este esqueleto:

<html>
    <head>
        <title>Título de la pestaña</title>
        <meta charset="UTF-8">
    </head>
    <body>
        Aquí va todo lo que se ve en la página
    </body>
</html>
  • <html>
    • Elemento principal y raíz del documento.
    • Todo el código de la página va dentro de él.
  • <head>
    • Cabecera: información sobre la página que no se ve en ella.
    • Va justo debajo de <html>.
    • Dentro suelen ir <title> y <meta> (y más adelante <link>, <style> y <script>).
  • <title>
    • Texto que aparece en la pestaña/barra de título del navegador.
  • <meta>
    • Indica la codificación de caracteres para que se vean bien las tildes y la ñ.
    • Lo normal: <meta charset="UTF-8"> (otra opción antigua: ISO-8859-1).
    • Forma larga: <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
  • <body>
    • Cuerpo: todo lo que se ve en la página.
    • Atributos:
      • bgcolor → color de fondo.
      • background → imagen de fondo.
      • text → color del texto.
      • leftmargin / topmargin → márgenes izquierdo y superior.
      • link → color de los enlaces sin visitar.
      • vlink → color de los enlaces ya visitados.
      • alink → color del enlace en el momento de pulsarlo.
✎ Ejemplo: esta misma página usa 
<body bgcolor="#0B1E3F" text="#FFFFFF" link="#00FFFF" vlink="#C0C0C0" alink="#FFFF00">

III. Etiquetas relacionadas con texto

► Títulos: <h1> ... <h6>

Hay 6 niveles, de mayor (h1) a menor (h6). Admiten el atributo align = left | center | right | justify.

Título h1

Título h3

Título h6

► Párrafos y bloques

  • <p> → párrafo. Atributo align (left, center, right, justify).
  • <div> → bloque/división. También admite align.
  • <center> → centra todo lo que tiene dentro.
  • <br> → salto de línea (sin cierre).
  • <pre> → texto preformateado: respeta los espacios y saltos de línea tal y como se escriben.
  • <blockquote> → cita; el texto aparece con sangría.

► Línea horizontal: <hr>

Atributos: align, width (ancho en px o %), size (grosor) y noshade (sin sombra, línea sólida).

► Formato de letra: <font>

  • face → tipo de letra: Times New Roman, Comic Sans MS, Courier New...
  • color → red, #00FF00, yellow...
  • size → de 1 a 7: 1 2 3 4 5 6 7

► Estilos de texto

  • <b> → negrita
  • <i> → cursiva
  • <u> → subrayado
  • <s> → tachado
  • <tt> → letra de máquina de escribir
  • <big> → más grande
  • <small> → más pequeño

► Texto en movimiento: <marquee>

  • behavior → scroll (pasa y vuelve a empezar), slide (pasa y se para), alternate (rebota).
  • direction → up, down, left, right.
  • bgcolor → color de fondo de la marquesina.
★ Ejemplo: behavior="scroll" direction="left" ★
★ Ejemplo: behavior="slide" direction="right" ★

IV. Caracteres especiales (entidades)

Algunos caracteres no se pueden escribir directamente porque HTML los usa (como < o >) o porque pueden dar problemas de codificación. Se escriben con una entidad: empiezan por & y acaban en ;. 

Carácter    Entidad          Carácter    Entidad
  <         &lt;               €         &euro;
  >         &gt;               &         &amp;
  á         &aacute;           "         &quot;
  é         &eacute;           ¿         &iquest;
  í         &iacute;           ¡         &iexcl;
  ó         &oacute;           ç         &ccedil;
  ú         &uacute;           ü         &uuml;
  ñ         &ntilde;           ·         &middot;
  Ñ         &Ntilde;           º ª       &ordm; &ordf;
  ©         &copy;             ®         &reg;
  ™         &#153;             ¬         &not;
  • Las mayúsculas acentuadas se escriben igual pero con la primera letra en mayúscula: &Aacute; = Á
  • &nbsp; → espacio en blanco que no se "come" el navegador. Sirve para meter varios espacios seguidos: A     B

V. Colores

Los colores se indican con su nombre en inglés o en hexadecimal: #RRGGBB (dos cifras para el rojo, dos para el verde y dos para el azul, de 00 a FF).
